# Sabrine Birthday Website

A responsive, seven-section static birthday website built with HTML, CSS and vanilla JavaScript.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. For the best local testing experience, use VS Code Live Server.

No backend, database, build tools or package installation are required.

## Add background music

The music button is optional and user-controlled. Add an audio file named `music.mp3` inside the `assets` folder:

`assets/music.mp3`

Use a track you have permission to use. The page will not autoplay music.

## Personalize before sharing

Edit `index.html` and `js/script.js`:
- Replace the starter reason cards with real, specific details.
- Check every timeline milestone and remove or correct anything inaccurate.
- Rewrite the letter in your own voice.
- Update the signature if needed.
- Add a music file if you want background music.

The current text is starter copy, not a claim that every detail matches your relationship.

## Publish

You can publish the folder as a static site using GitHub Pages or Netlify. Upload the contents of this folder, keeping the `css`, `js`, and `assets` folders in the same structure.

## Privacy note

This is a public static website once deployed. An unlisted URL is not password protection: anyone who receives or discovers the link may open it. Do not include private chat screenshots, sensitive information, or anything Sabrine would not want shared.


## Final personalization notes
- The letter and story are personalized in Arabic using details from your conversation and the details you supplied.
- Background music remains optional. Add a legally usable audio file named `music.mp3` inside `assets/` if you want the music button to work.
- An unlisted link is not password protection: anyone who receives the URL can open the site.
- Before sharing, open `index.html` on a phone and check the text, layout, candle interaction, letter opening, and music button.


## تحديث تجربة الاستخدام
- أصبحت الفصول السبعة منفصلة؛ يظهر فصل واحد فقط في كل مرة.
- الانتقال بين الفصول يتم بزرّي السابق والفصل التالي أسفل الشاشة، مع مؤشر يوضح رقم الفصل.
- أزيلت قائمة الروابط والانتقالات المعتمدة على تمرير الصفحة.
- واجهة الموقع ومحتواه الظاهر باللغة العربية.


## الرسالة الشخصية
- تظهر الرسالة داخل ظرف صغير؛ عند الضغط عليه يختفي الظرف وتظهر الرسالة كاملة.
- الاعتراف الأخير موجود في أسفل الفصل الأخير كما حدده صاحب الموقع.
- بطاقات الأشياء الستة مستخلصة من الرسالة الشخصية.
